# IT Service Log

برنامه‌ی ثبت و گزارش‌گیری خدمات روزانه‌ی واحد IT و واحد سایت.

- **ثبت روزانه:** هر کارشناس برای هر روز یک برگه دارد؛ خدمات کلی فقط با «تعداد» ثبت
  می‌شوند و نیازی به نام مراجعه‌کننده نیست. خدماتی که در «مدیریت خدمات» با گزینه‌ی
  «نیاز به نام فرد» علامت خورده‌اند (ارتقا، اسمبل سیستم، نصب ویندوز) تک‌تک و با نام ثبت می‌شوند.
- **تفکیک بخش‌ها:** صفحه‌ی ثبت واحد سایت از واحد IT جداست و هر کاربر فقط بخش خودش را می‌بیند.
- **مدیریت خدمات:** افزودن، ویرایش عنوان، تغییر حالت ثبت، انتقال بین بخش‌ها و حذف.
- **گزارش‌ها:** فیلتر بر اساس تاریخ، بخش و کارشناس + خروجی اکسل چهار شیتی.

## اجرا

```
pip install -r requirements.txt
python main.py
```

ورود پیش‌فرض: `admin` / `admin` (حتماً تغییر دهید).
